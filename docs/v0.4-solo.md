# Sunbird v0.4-solo

`v0.4-solo` is the single-character action-RPG research branch built from the common v0.4 runtime foundation.

## Milestone A: direct play

The first solo milestone intentionally remains discrete/input-stepped. It changes gameplay policy before changing scheduling or geometry.

```text
Session
└── Character :player

Mode::Play
├── move
├── attack
└── interact / Dialogue

TurnPlanner
    ↓
Simulation::Commands::Buffer
    ↓
Simulation::Executor
    ↓
World + persistent Effects
```

Differences from the JRPG-oriented line:

- no Party abstraction in the solo runtime;
- no `Mode::Battle`;
- combat occurs directly against adjacent World entities;
- Space is `:attack`;
- Enter is `:interact`;
- a whiffed attack still consumes a simulation step, so NPC behavior continues;
- a local zero-HP attacker cannot execute a queued Attack after an earlier command defeats it.

Still deliberately unchanged:

- integer grid Position;
- one Simulation step per actionable input event;
- `TurnPlanner` for movement and NPC behavior;
- `Commands::Buffer`;
- Executor and persistent Effects;
- pathfinding;
- Kitty rendering and current blocking terminal input.

## Next milestone

The next solo milestone should be an input/timing spike, not continuous geometry yet:

1. Kitty keyboard press/release support and non-blocking polling;
2. held-input state;
3. monotonic fixed-step accumulator, initially around 30 ticks/second;
4. NPCs continue to act when the player supplies no input;
5. render independently from simulation timing.

Only after that is stable should the branch add attack windup/active/recovery, projectiles, pickups, continuous coordinates, velocity, or broader collision.
